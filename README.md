# 米家产品示例样图库 · mijia-product-icons

> 米家（Xiaomi Mi Home）在架产品示例样图快照库。图片与配套清单已按大类整理，供个人学习、研究与软件测试使用。

- 数据来源：米家百科公开产品库 <https://home.mi.com/webapp/content/baike/index.html#/>
- 快照日期：**2026-09-28**（当天从在线产品库接口采集，属"在架产品库"时点快照；上一期快照为 2026-09-03，见[更新清单_2026-09-28.md](更新清单_2026-09-28.md)）
- 覆盖范围：**17 个大类 / 10,533 个在架产品型号 / 10,532 张在架示例样图**（其中 1 个型号采集时无图，位于"环境电器"类）；另**保留 14 个官网已移除型号**的信息与样图备查
- 图片格式：按原始图片实际格式保存，扩展名为 `.png` / `.jpg` / `.gif` / `.webp`
- 文件命名：示例样图文件名 = 产品型号，例如 `zhimi.heater.za1.png`
- 归类口径：「新上线」为米家百科的滚动上新货架，货架上的型号一律归入其真实大类，仅"尚未归入任何真实大类"的型号保留在「新上线」类（当前 1 个）；每个型号全库只计一次
- 保留策略：官网已移除的型号不做本地删除——清单条目保留在各 CSV 末尾并备注「官网已移除该型号」，样图仍保留在图片目录中
- Windows 检出说明：有 2 张图片的文件名以 Windows 保留设备名 `aux.` 开头（`aux.aircondition.hc1.png`、`aux.aircondition.v1.png`，属"环境电器"类），Windows 无法检出/解压此类文件名，已从仓库目录树剔除；完整 10,546 张均包含在 Releases 压缩包中

## 清单字段

`清单/00_总清单.csv`（UTF-8 with BOM，Excel 可直接打开）每行对应一个产品型号，字段为：`大类`、`品牌`、`产品名称`、`型号`、`图片文件名`、`备注`。官网已移除的型号仍按其原大类与原排序位置保留在各 CSV 中，`备注` 列标注「官网已移除该型号」，其余行 `备注` 为空，可按备注列筛选。`清单/下架清单.csv` 单独汇总历期官网移除的型号（含最后在架快照与下架确认快照日期），后续更新继续追加。`清单/按大类/` 下是各分类子清单；`清单/_说明.txt` 为清单生成说明。
